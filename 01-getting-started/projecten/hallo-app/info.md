# hallo-app — Je eerste zelfstandige programma

> 🎯 **Waarom?** Dit is je "Hello World": je eerste échte programma dat tekst en rekenwerk combineert.

## Wat je leert
- `print()` voor uitvoer
- Variabelen maken en gebruiken
- Tekst samenvoegen met het plusteken (`+`)
- Eenvoudig rekenen

## De opdracht
Schrijf een programma dat:
1. Een variabele `naam` maakt met jouw naam.
2. `Hallo <naam>!` afdrukt door tekst samen te voegen met `+`.
3. Daarna twee getallen optelt en het resultaat afdrukt.

## Starten
```bash
python main.py
```

## Uitdaging
Maak er een klein rekensommetje van: druk ook een aftrekking en een vermenigvuldiging af.
